# 位运算+二进制数位处理+sort&lambda：按照二进制下1的数目排序



#位运算 # 排序

> Problem: [1356. 根据数字二进制下 1 的数目排序](https://leetcode.cn/problems/sort-integers-by-the-number-of-1-bits/description/)﻿﻿

## 思路

- 非常简单，计数二进制中的1
- 结合1位的数量，以及数值大小两个条件进行排序

## 解题过程(计数1)

- BK算法

  - ` element &= (element-1) `

- 硬件接口

  - `#include <bit> `

  - ` std::popcount(<unsigned int>) `
    - 注意事项：需要从 int 强制转换到`unsigned int>

## 复杂度

- 时间复杂度: O(nlogn⋅k):主要是排序,k是二进制位数

- 空间复杂度: O(logn): 排序

  

## 注意事项

- 在sort中的lambda函数，由于需要使用私有函数 _oneNumber ，需要捕获 this ，意味着把这个**类的指针**传过去。
- 注意在使用 std::popcount() 函数的时候，里面接收的参数有类型限制，必须是无符号整数。
  - 这需要转换一下
  - ` static_cast<unsigned int>(ele2) `

//硬件接口计数
#include <bit>
class Solution {
public:
    vector<int> sortByBits(vector<int>& arr) {
        sort(arr.begin(), arr.end(), [](int ele1, int ele2) {
            int count1 = std::popcount(static_cast<unsigned int>(ele1));
            int count2 = std::popcount(static_cast<unsigned int>(ele2));
            
            if (count1 != count2) return count1 < count2;
            return ele1 < ele2; // 1的个数相同时，按数值升序
        });
        return arr;
    }
};
