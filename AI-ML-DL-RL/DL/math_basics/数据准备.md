# 数据准备

## 数据预处理（Data Preprocessing）

### 重复数据

- 避免对权重进行“感染”（干扰训练分布）
- 防止模型偏置放大

------

### 荒谬的数据

- 逻辑不合理值
- 超物理/业务约束范围值

------

### 非格式化的数据

- nan
- 空格
- 问号

------

### 有空缺的数据

- 缺失值（missing value）

------

### 字符串处理

- 在预处理最后一步，把字符串转换成数值表示
  - 编码后再进入模型

------

## 数据归一化 / 标准化（Normalization / Standardization）

### 归一化（Normalization）

- 映射到区间
  - [0, 1]
  - [-1, 1]

------

### 标准化（Standardization）

- 均值 0 化
- 方差 1
- 约 68% 数据落在 [-1, +1] 区间（正态分布假设）

------

### Transformer 说明

- transformer 是对象（转换器对象）
- 可保留生成转换器时的数据特征
  - 均值
  - 方差

#### 数据泄露约束

- 训练集拟合 transformer
- 验证集 / 测试集只做 transform
- 不能重新 fit
- 交叉验证同样禁止泄露

------

### 归一化 / 标准化的 wise（作用维度）

#### 样本级（sample-wise）

- 当特征列表示同一个物理特征时
- 常用于音波数据
- 按照**单个样本的所有特征**做归一化 / 标准化

#### 特征级（feature-wise）

- 列特征不表示同一个特征
- 基于列进行处理
- 最常用模式

#### 元素级（element-wise / global）

- 用于特征列全部表示同一类信息
- 全局元素统一做一组变换操作

------

### 还原（Inverse Transform）

- 使用之前保存的 transformer
- 进行反归一化 / 反标准化

------

- 从像素空间
