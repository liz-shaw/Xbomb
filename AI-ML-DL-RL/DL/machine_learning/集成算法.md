# 集成算法（Ensemble Methods）

## 投票（Voting）

### 计数投票

- 多数表决
- 适用于同质模型集成

### 权重投票

- 加权表决
- 权重来源
  - 模型性能
  - 验证集指标
  - 经验设定

------

## Bagging（Bootstrap Aggregating）

### 样本处理

- 对样本进行 bootstrap 抽样
  - 有放回采样
  - 形成不同训练子集

### 超参数

- bootstrap 样本大小
- 需要的决策树数量

------

### 进行预测

#### 分类问题

- 投票

#### 值预测（回归）

- 均值

------

### 关键点

- 决策树数量一般选择和分类类数相同（经验策略）
- 决策树过多会导致边际收益降低（边界收益递减）
- 主要降低方差（variance reduction）

------

## 随机森林（Random Forest）

- bootstrap 抽样
- 结点随机选择特征进行分裂
- 特征子空间随机化（feature subspace sampling）
- 核心作用
  - 去相关性
  - 降低模型间相关性

------

## 极端随机树（Extra Trees / Extremely Randomized Trees）

- 不进行 bootstrap 抽样（使用全样本）
- 分裂点随机选择阈值 + 随机选择特征
- 结点按照随机选择的特征进行分裂
- 牺牲部分准确率
- 换取防止过拟合能力
- 增强随机性 → 降低方差

------

## Boosting

### 基本思想

- 用弱学习器进行二分
- 串行训练（Sequential）
- 后一模型关注前一模型错误样本

#### 弱学习器特性

- 稍微比随机预测好一点
- error < 0.5（二分类假设）

------

### 随机预测模型

#### 区分是否是随机预测

- 混淆矩阵
- 置换检验
  - 先把所有样本的标签打乱
  - 再进行训练
  - 若性能不变 → 模型无信息学习能力
- ROC 曲线呈现对角线

#### 随机预测种类

- 永远预测频率高的类别
- 按比例预测
- 完全随机预测

------

### 二分后区域赋值

- 正面的 +1
- 反面的不加（或 -1，依算法定义）

------

### 权重机制

- 给每个二分弱学习器赋予权重
- 权重与分类误差相关
  - 错误率越低 → 权重越大

------

### 输出机制

- 通过权重的符号加权求和
- 进行最后的二分类判别
