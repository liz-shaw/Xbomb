### 类继承

**继承基础语法** 派生类通过在类名后使用冒号声明继承方式。基类的成员根据继承准则映射到派生类中。

**成员访问权限控制** 继承方式决定了基类成员在派生类中的最高访问级别：

- **public 继承**：保持基类成员原有属性。
- **protected 继承**：基类 public 成员在派生类中变为 protected。
- **private 继承**：基类所有成员在派生类中变为 private。

**构造与析构顺序**

- **构造**：先调用基类构造函数（按继承列表顺序），再初始化派生类成员，最后执行派生类构造函数体。
- **析构**：执行顺序与构造完全相反。基类析构函数必须声明为 **virtual**，否则通过基类指针删除派生类对象时会发生内存泄漏。

**虚函数与多态**

- **virtual**：允许在派生类中重写函数，通过基类引用或指针实现动态绑定。
- **override**：明确标识重写意图，编译器会检查函数签名是否一致。
- **final**：禁止类被继承或虚函数被进一步重写。
- **纯虚函数**：形如 `virtual void func() = 0;`。含有纯虚函数的类为抽象类，不可实例化。

### 基础代码模板



```C++
#include <iostream>

// 基类定义
class Base {
public:
    Base(int val) : data(val) {}
    virtual ~Base() {} // 必须为虚析构

    virtual void display() const {
        std::cout << "Base: " << data << std::endl;
    }

protected:
    int data;
};

// 派生类定义
class Derived : public Base {
public:
    // 使用初始化列表调用基类构造函数
    Derived(int b_val, int d_val) : Base(b_val), extra_data(d_val) {}

    // 显式重写虚函数
    void display() const override {
        std::cout << "Derived: " << data << ", " << extra_data << std::endl;
    }

private:
    int extra_data;
};

int main() {
    // 多态使用示例
    Base* ptr = new Derived(10, 20);
    ptr->display(); 
    
    delete ptr; // 触发虚析构
    return 0;
}
```

### 抽象类（接口）模板



```C++
class IShape {
public:
    virtual ~IShape() {}
    // 纯虚函数，子类必须实现
    virtual double getArea() const = 0;
    virtual void draw() = 0;
};

class Circle : public IShape {
public:
    Circle(double r) : radius(r) {}
    
    double getArea() const override {
        return 3.14159 * radius * radius;
    }
    
    void draw() override {
        // 实现具体逻辑
    }

private:
    double radius;
};
```
