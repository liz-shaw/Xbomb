# 命令行参数传递

## 定义

这两个参数通常出现在 `main` 函数的括号里： `int main(int argc, char* argv[])`

- **`argc` (Argument Count):** 这是一个整数，代表传递给程序的参数**数量**。
  - *注意：* 程序本身的名称总是第一个参数，所以 `argc` 至少为 1。
- **`argv` (Argument Vector):** 这是一个字符串数组（更准确地说是字符指针数组）。它存储了具体的**参数内容**。
  - `argv[0]`：程序的路径或名称。
  - `argv[1]`：第一个用户输入的参数。
  - `argv[n]`：第 n 个参数。

------

##  技术原理解析

这种技术属于**操作系统与应用程序之间的接口**。当你按下回车执行命令时，操作系统会把这一行字符串切分成若干块，填入内存，并将这些地址传递给你的 `main` 函数。

------

## 代码示例

下面是一个经典的例子，它会打印出你输入的所有参数，并演示如何根据参数执行逻辑。

```C++
#include <iostream>

int main(int argc, char* argv[]) {
    // 1. 告知用户参数的数量
    std::cout << "收到参数个数 (argc): " << argc << std::endl;

    // 2. 遍历并打印所有参数
    for (int i = 0; i < argc; ++i) {
        std::cout << "argv[" << i << "]: " << argv[i] << std::endl;
    }

    // 3. 简单的逻辑判断示例
    if (argc > 1) {
        std::string firstArg = argv[1];
        if (firstArg == "--help") {
            std::cout << "【帮助信息】：这是一个演示命令行参数的程序。" << std::endl;
        }
    }

    return 0;
}
```

- 运行

  - 假设你编译后的程序叫 `myprog`：

  - **输入：** `./myprog hello world`

  - **输出：**
    - `argc`: 3
      - `argv[0]`: `./myprog`
      - `argv[1]`: `hello`
      - `argv[2]`: `world`
