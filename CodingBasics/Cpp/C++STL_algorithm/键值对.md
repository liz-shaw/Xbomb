# 📚 C++ 键值对（Map）容器

在 C++ STL 中，存储键值对（Key-Value）的容器主要有四种。它们可以从 **“是否有序”** 和 **“是否允许重复键”** 两个维度来区分。

### 一、 核心容器对比表

| **容器名称**                  | **底层实现** | **排序情况**        | **查找复杂度**  | **允许重复键** |
| ----------------------------- | ------------ | ------------------- | --------------- | -------------- |
| **`std::map`**                | 红黑树       | **按 Key 自动排序** | $O(\log n)$     | 否             |
| **`std::unordered_map`**      | 哈希表       | 无序                | **平均 $O(1)$** | 否             |
| **`std::multimap`**           | 红黑树       | 按 Key 自动排序     | $O(\log n)$     | **是**         |
| **`std::unordered_multimap`** | 哈希表       | 无序                | 平均 $O(1)$     | **是**         |

------

### 二、 详细拆解

#### 1. std::map (有序映射)

- **特点**：内部元素始终按 Key 升序排列。
- **优点**：支持**范围查找**（比如查找 Key 在 [10, 50] 之间的元素）。
- **缺点**：查找速度比哈希表略慢。
- **要求**：Key 类型必须支持 `<` 运算符（可比较大小）。

#### 2. std::unordered_map (无序映射)

- **特点**：元素位置由哈希函数决定。
- **优点**：**性能最高**，是大多数场景下的首选方案。
- **缺点**：不支持范围查找，且在极端哈希冲突下性能会下降。
- **要求**：Key 类型必须支持 `==` 运算符，并且能计算 Hash 值（基本类型如 `int`, `string` 已内置支持）。

#### 3. Multimap 版本 (允许重复键)

- 如果你需要一个键对应多个值（例如：一本字典里，一个单词有多个解释），就使用 `multimap` 或 `unordered_multimap`。
- **注意**：`multimap` **不支持** `[]` 下标操作，因为一个键对应多个值，编译器不知道你要哪个。

------

### 三、 常用操作代码模板 (以 map 为例)



```c++
#include <map>
#include <unordered_map>

// 1. 初始化
std::map<string, int> m;

// 2. 插入 (两种常用方式)
m["Apple"] = 10;                // 方式A：直观，若键存在则更新，不存在则创建
m.insert({"Banana", 20});      // 方式B：更高效，但若键已存在则插入失败

// 3. 查找
if (m.find("Apple") != m.end()) {
    // 找到了
}

// 4. 遍历 (C++17 结构化绑定，最推荐)
for (auto const& [key, value] : m) {
    cout << key << " : " << value << endl;
}

// 5. 删除
m.erase("Apple");
```
