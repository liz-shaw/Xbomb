# 神经网络概论

## 深度学习层

### 输入输出

#### 输入层

- 可以理解为一个内存块
- 严格来说，不属于神经网络的计算层结构

#### 输出层

- 输出层神经元数量依赖具体任务
  - 分类任务 → 分类数
  - 回归任务 → 预测维度

------

### 功能层

#### 全连接层（FC layer / Dense layer）

- 每个神经元与上一层所有神经元连接
- 全连接神经网络（MLP）由多层 FC 层堆叠而成

#### 激活函数层

- 为网络引入非线性
- 常用激活函数：ReLU、Sigmoid、Tanh

#### Dropout 层

- **训练阶段**：
  - 确定 dropout 比例
  - 对每个 epoch：
    - 随机选择前一层一定比例的神经元
    - 暂时断开它们与其他神经元的连接
    - 前向传播 + 反向传播更新权重
    - 恢复被断开的神经元连接
- **预测阶段**：
  - 恢复所有神经元连接
- **作用**：
  - 防止单个神经元专门化
  - 提高网络冗余性与稳健性

#### Batch Normalization 层（批归一化层）

- **只做计算，没有可训练参数（γ, β 可选）**
- **作用**：
  - 改变输出绝对大小，但保持相对关系
  - 保持网络内部数值分布稳定 → 推迟过拟合
  - 确保激活函数接收到的输入在有效区间

#### 卷积层（Convolution Layer）

- 使用过滤器（kernel）提取特征
- **优点**：
  - 参数共享
  - 并行计算

#### 池化层（Pooling Layer）

- 常用于改变特征图尺寸
- **顺序**：
  - 一般放在卷积层之后

#### 循环层（Recurrent Layer）

- 可以记忆历史信息
- 常用于序列数据、时间序列或文本

#### 其他工具层

- 归一化层（Normalization Layer）
- 噪声层（Noise Layer）
- reshape 层
- 裁剪层（Crop Layer）
- padding 层
- 上采样层（Upsample Layer）
- flatten 层
  - 例如图像分类：
    - 将图像 flatten 成一维向量
    - 输入全连接层
    - 输出分类神经元
    - 最终通过 Softmax 得到分类概率

------

## 深度学习的两个主要缺陷

1. **缺乏可解释性**
2. **数据具有情景性和历史性**
   - 泛化能力受限
   - “垃圾进 → 垃圾出”（Trash in, Trash out）

------

## 构建深度学习器的过程

1. 数据准备
2. 选择网络结构
3. 选择参数（超参数 + 权重初始化）
4. 运行系统
5. 试错、迭代与优化
