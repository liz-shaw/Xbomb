# 分治

## 主定理 (Master Theorem)

### 定理表述

主定理用于快速求解分治算法中形如以下形式的递归式渐近复杂度：

$$T(n) = aT(n/b) + f(n)$$

**参数含义：**

- $a \ge 1$：子问题的个数。
- $b > 1$：子问题的规模缩减倍数。
- $f(n)$：递归之外的开销（分解与合并子问题的代价）。

------

### 三种核心情况

判定步骤：首先计算**临界指数** $c_{\text{crit}} = \log_b a$，然后将 $f(n)$ 与 $n^{c_{\text{crit}}}$ 进行比较。

#### 情况 1：子问题开销占主导

如果存在常数 $\epsilon > 0$，使得 $f(n) = O(n^{c_{\text{crit}} - \epsilon})$：

即 $f(n)$ 的增长多项式级慢于 $n^{c_{\text{crit}}}$。

$$T(n) = \Theta(n^{\log_b a})$$

#### 情况 2：两者基本平衡

如果存在常数 $k \ge 0$，使得 $f(n) = \Theta(n^{c_{\text{crit}}} \log^k n)$：

即 $f(n)$ 与 $n^{c_{\text{crit}}}$ 同阶（允许差一个对数因子）。

$$T(n) = \Theta(n^{c_{\text{crit}}} \log^{k+1} n)$$

> *注：*
>
> * 最常用的是 $k=0$，此时 $T(n) = \Theta(n^{c_{\text{crit}}} \log n)$。
> * 无论给 $\log$ 加多少次方（$\log^{100} n$），它在增长速度上都**永远追不上**任何一个 $n^{\epsilon}$（比如 $n^{0.001}$）

#### 情况 3：合并开销占主导

如果存在常数 $\epsilon > 0$，使得 $f(n) = \Omega(n^{c_{\text{crit}} + \epsilon})$，且满足**正则性条件**（$a f(n/b) \le c f(n)$ 对于 $c < 1$ 成立）：

即 $f(n)$ 的增长多项式级快于 $n^{c_{\text{crit}}}$。

$$T(n) = \Theta(f(n))$$

------

### 经典算法复杂度

| **算法名称**       | **递归关系式**            | **a,b** | **f(n)** | **比较结果**         | **复杂度 T(n)**        |
| ------------------ | ------------------------- | ------- | -------- | -------------------- | ---------------------- |
| **二分查找**       | $T(n) = T(n/2) + O(1)$    | $1, 2$  | $n^0$    | $n^0 = n^{\log_2 1}$ | $\Theta(\log n)$       |
| **归并排序**       | $T(n) = 2T(n/2) + O(n)$   | $2, 2$  | $n^1$    | $n^1 = n^{\log_2 2}$ | $\Theta(n \log n)$     |
| **Karatsuba 乘法** | $T(n) = 3T(n/2) + O(n)$   | $3, 2$  | $n^1$    | $n^1 < n^{\log_2 3}$ | $\Theta(n^{\log_2 3})$ |
| **Strassen 矩阵**  | $T(n) = 7T(n/2) + O(n^2)$ | $7, 2$  | $n^2$    | $n^2 < n^{\log_2 7}$ | $\Theta(n^{\log_2 7})$ |

------

### 主定理的失效场景

即使递归式长得很像，以下情况也**不能**使用主定理：

1. **$a$ 不是常数**：例如 $T(n) = n T(n/2) + n$。
2. **$f(n)$ 不是正函数**：例如 $f(n)$ 包含减法或交替符号。
3. **差距非多项式级**：
   - 例如 $T(n) = 2T(n/2) + n \log n$。
   - 虽然 $n \log n$ 比 $n^1$ 快，但它不快于 $n^{1+\epsilon}$（对数增长慢于任何正幂次）。这种情况属于主定理的“间隙”，需改用递归树法。



## 适合分治法的问题

- 平衡子问题： 子问题的规模大致相同。一般子问题规模相等处理的效率比不相等的效率更高

- 独立子问题：子问题之间相互独立

  - 不像大部分动态规划，子问题之间可以是前后依赖的
