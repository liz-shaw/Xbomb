# 回归（Regression）

## 线性回归

- 模型形式

$y = a_0 + a_1x_1 + a_2x_2 + \dots $

------

## 岭回归（Ridge Regression）

- L2 正则化

### 损失函数

$Loss=∑error2+λ∑ai2Loss = \sum error^2 + \lambda \sum a_i^2Loss=∑error2+λ∑ai2$

- lambda = 正则强度（sklearn 中为 alpha）

------

## Lasso 回归

- L1 正则化

$Loss=∑error2+λ∑∣ai∣Loss = \sum error^2 + \lambda \sum |a_i|Loss=∑error2+λ∑∣ai∣$

- 具备稀疏性（特征选择效果）

------

## 弹性网（Elastic Net）

- L1 + L2 结合

#### 结构

- 两个的结合

#### 注意

- L2 项权重系数通常除以 2（标准化形式）
- sklearn 中：
  - alpha：总正则强度
  - l1_ratio：L1 与 L2 比例系数
