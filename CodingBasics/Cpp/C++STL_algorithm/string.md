### C++ `std::string`

`std::string` 本质上是一个动态管理内存的字符顺序容器。它比 C 语言中的 `char*` 更安全，因为其内部自动处理扩容与回收，避免了缓冲区溢出的风险。

------

### **常用成员函数速查表**

| **功能分类** | **函数/操作符**                 | **简要说明**                                |
| ------------ | ------------------------------- | ------------------------------------------- |
| **基础访问** | `s[i]` 或 `s.at(i)`             | 获取第 $i$ 个字符（`at` 会检查越界）        |
| **获取尺寸** | `s.size()` / `s.length()`       | 返回字符串长度（两者等效）                  |
| **容量操作** | `s.empty()` / `s.clear()`       | 检查是否为空 / 清空内容                     |
| **拼接内容** | `s += "tail"` / `s.append(str)` | 在末尾追加字符串                            |
| **截取子串** | `s.substr(pos, len)`            | 从 `pos` 开始截取长度为 `len` 的子串        |
| **查找定位** | `s.find("target")`              | 返回首次出现的位置，失败返回 `string::npos` |
| **修改替换** | `s.replace(pos, len, str)`      | 将指定范围替换为新字符串                    |

------

### **性能优化：常量引用与 SSO**

在编写函数时，应当尽量避免直接按值传递 `std::string`，因为这会触发深拷贝（Deep Copy），耗费 CPU 时间和内存。

> **最佳实践：** 传参时使用 `const std::string& s`。

此外，现代 C++ 编译器普遍采用 **SSO (Small String Optimization)** 技术。当字符串长度较短（通常在 15-23 字节以内）时，数据会直接存储在 `string` 对象自身的栈空间内，而不去堆（Heap）上申请内存，从而极大地提升了小字符串的处理效率。

------

### **输入方式的区别**

| **方式**                   | **读取表现**                     | **适用场景**           |
| -------------------------- | -------------------------------- | ---------------------- |
| **`std::cin >> s`**        | 遇到**空格、制表符、换行**即停止 | 读取单词或连续字符     |
| **`std::getline(cin, s)`** | 遇到**换行符**才停止             | 读取包含空格的完整句子 |

------

### **与 C 风格接口的互操作**

由于许多底层系统函数（如 `fopen`）只接受 `const char*`，你需要掌握以下转换方式：

- **String 转 C-string**：调用 `s.c_str()`。
- **数值转换**：使用 `std::to_string(123)` 将数字转为字符串；使用 `std::stoi("123")` 将字符串转为整数。
